① 自動行情與研究資料

輸入台股代號即可從原本 Fibo 4.0 使用的 Cloudflare Workers API 載入歷史日 K；CSV 保留作為備援。資料不足時不輸出交易訊號。

輸入股票代號並按「取得歷史行情並分析」。CSV 匯入不會上傳至伺服器。

② 確認型波段與 Fibonacci

Pivot 必須等右側指定根數的 K 棒完成才確認；最新未確認轉折不計入。以最近一組交替高低點計算，非保證有效的交易價位。

③ VCP 候選型態（研究版）

採近三個不重疊 20 日區間的最高最低振幅收縮作簡化篩選，並觀察成交量與均線；不等同原專案完整 VCP 定義。結果為候選提示，不是買賣建議。

④ 風險部位試算

台股一般股票以 1,000 股為一張；零股、手續費、滑價與跳空風險另計。
